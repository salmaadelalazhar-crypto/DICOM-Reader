# قارئ الأشعة الطبية DICOM — برنامج سطح المكتب

برنامج ويندوز لمساعدة الأطباء وذوي الإعاقة البصرية في قراءة ملفات الأشعة DICOM وتفسيرها. الواجهة مبنية بـ **PySide6 (Qt)**: نافذة برنامج عادية تعمل مباشرة على الجهاز، بلا متصفح ولا خادم محلي ولا WebView2.

> التقرير وصف تقني آلي للمساعدة وليس تشخيصاً طبياً؛ مراجعة طبيب الأشعة ضرورية دائماً.

## الميزات
- فتح ملف ‎.dcm‎ أو ‎.zip‎ (حتى 200 ميجابايت) بزر «اختيار ملف» أو بالسحب والإفلات، أو بفتح الملف بالبرنامج مباشرة.
- تحليل MONAI (مع بديل NumPy) للصورة: الإضاءة، التباين، الإنتروبيا، الحواف، البنية الساطعة، التماثل.
- تقرير وصفي عربي/إنجليزي حسب لغة ويندوز، مع الاستماع إليه (gTTS، MP3) وحفظ الصوت، وقارئ بديل بأصوات ويندوز دون إنترنت.
- Excel لكل ملف ولكل الدفعة، اتجاه من اليمين لليسار بالعربية.
- تقرير Gemini تلقائي، وأسئلة إضافية بالكتابة أو بالتحدث بالميكروفون، مع مرفقات (PDF، صور، نصوص)، وصوت لكل رد.
- شاشة إعداد مفتاح Gemini بالخطوات؛ يُحفظ المفتاح على جهاز المستخدم فقط.

## التشغيل من المصدر (للمطوّر)
```bash
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
python main.py
```

## إنشاء برنامج ويندوز EXE
راجع **DESKTOP_GUIDE.md** (عبر GitHub Actions، دون تثبيت أي شيء على جهازك).

## الاختبارات
```bash
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
```

## هيكل المشروع
- `main.py` — نقطة تشغيل البرنامج.
- `core/processing.py` — قراءة DICOM وتحليل MONAI والتقرير وExcel والصوت (بلا واجهة).
- `gui/` — نافذة البرنامج: النتائج، الدفعة، Gemini، شاشة المفتاح، مشغل الصوت.
- `monai_gemini/` — البرومبت وخدمة Gemini ومنطق المحادثة.
- `desktop/` — اللغة والترجمة، حفظ المفتاح، الميكروفون، فحص البرنامج المُجمّع.
