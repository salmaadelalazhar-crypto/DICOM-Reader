# قارئ الأشعة الطبية DICOM

تطبيق ويب مبني بـ Streamlit لمساعدة الأطباء وذوي الإعاقة البصرية في قراءة ملفات الأشعة الطبية DICOM وتفسيرها.

## التشغيل محلياً

```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud

1. ارفع الملفات (app.py، requirements.txt، مجلد .streamlit) إلى مستودع GitHub.
2. في share.streamlit.io اضغط New app واختر المستودع والملف الرئيسي app.py.

## الميزات

- رفع ملف .dcm منفرد أو ملف .zip مضغوط حتى 200 ميجابايت.
- معالجة جميع ملفات الأشعة داخل الملف المضغوط دفعة واحدة مع شريط تقدم.
- استخراج البيانات التقنية (نوع الجهاز، الجزء المفحوص، أبعاد الصورة...) وتحليل الصورة.
- تقرير نصي عربي مع إمكانية الاستماع إليه بصوت مسجل (gTTS).
- واجهة ميسّرة متوافقة مع قارئات الشاشة.

## ملاحظة

التقرير وصف تقني وليس تشخيصاً طبياً؛ مراجعة طبيب الأشعة ضرورية دائماً.


## تحديث Gemini المدمج

تم الحفاظ على قراءة DICOM منفرداً وداخل ZIP، تحليل MONAI والبديل NumPy، التقرير الوصفي، Excel الفردي والدفعي، وقارئ المتصفح. أُضيفت نافذة جانبية للنموذج والمرفقات وتسجيل الصوت وتحويله إلى نص قابل للتعديل، مع تقرير Gemini ومشغّل MP3 مستقل. يبقى الصوت الهندسي المحفوظ متاحاً مع تنزيل مستقل حتى بعد استخدام أزرار Gemini.

عند تحليل دفعة، اختر الملف المطلوب لـ Gemini أسفل النتائج. يُرسل التقرير النهائي مع جميع المؤشرات الرقمية الأصلية والبيانات التقنية؛ لا تُرسل مصفوفة البكسلات تلقائياً. عند عدم وجود نص أو مرفقات يُرسل البرومبت الافتراضي مرة واحدة للتقرير المحدد. التغيير إلى حالة أخرى يمسح محادثة Gemini وصوتها تجنباً لخلط الحالات.

### المفتاح والنقل بين المنصات

**المفتاح غير مكتوب داخل المصدر.** الدالة Python تعمل على الخادم وتقرأ GEMINI_API_KEY من أسرار الاستضافة. حفظ المفتاح في دالة داخل ZIP لا يجعله سرياً: كل من يملك الملف يمكنه قراءته. أسرار Lovable لا تنتقل تلقائياً إلى الاستضافة الخارجية.

- على Streamlit Community Cloud: افتح إعدادات التطبيق → Secrets، وأضف متغير GEMINI_API_KEY عبر نموذج الأسرار الخاص بالمنصة. لا تضف ملف أسرار إلى GitHub.
- على أي استضافة Python أو Docker: أضف GEMINI_API_KEY في متغيرات البيئة السرية؛ لا تغيّر الكود ولا تكتب المفتاح في Dockerfile.
- عند النقل إلى منصة أخرى يلزم إعداد السر هناك مرة واحدة؛ لا يطلبه التطبيق في كل إرسال.

### الصوت ومتطلبات النشر

ثبّت المتطلبات الموجودة في requirements.txt. يتطلب صوت Gemini تثبيت FFmpeg؛ على Streamlit Cloud يستخدم packages.txt المرفق، أو Dockerfile على منصة تدعم الحاويات. الصوت الهندسي الأصلي يبقى عبر gTTS مع قارئ المتصفح الاحتياطي عند فشل الخدمة. استخدم HTTPS لتسجيل الميكروفون.

الأسماء الأربعة مضبوطة على معرّفات Google الرسمية افتراضياً. إصدار 3.7 متوقف لدى Google وتحوّل Google طلباته إلى 3.8؛ يظهر تحذير عند اختياره. تُفحص النماذج المتاحة لحسابك قبل الإرسال. جودة التحليل والصوت ليست ضماناً طبياً، وتستلزم مراجعة مختص.

قبل النشر العام فعّل حماية دخول منصة الاستضافة وحدد من يستطيع استخدام الخدمة؛ النسخة الأصلية لا تتضمن نظام حسابات، ولم نضف واحداً أو نغيّر صلاحياتها. البيانات والمرفقات والتسجيلات المرسلة إلى Gemini تغادر خادمك إلى Google؛ يلزم تصريح ملائم للبيانات الطبية.

اختبارات محلية: `python -m unittest discover -s tests -v`. تفاصيل الإضافة وتوثيق Google في GEMINI_SETUP.md.
